# 01. Introduction to Multicloud

## Objetivo
Relacionar os serviços Oracle Multicloud aos provedores AWS, Azure e Google Cloud sem usar conta real.

## Material do curso
- Oracle Multicloud Solutions, 20 min.
- Multicloud Use Cases, 15 min.
- Skill Check, nota mínima 80%.

## Caso sintético: RetailFlow
A RetailFlow possui aplicações web em AWS, identidade corporativa em Azure, dados analíticos em Google Cloud e precisa avaliar Oracle AI Database@CSP para workloads transacionais. O ambiente de estudo não contém dados reais.

## Roteiro
1. Leia `case-study.md` e `data/provider-catalog.json`.
2. Revise o diagrama em `diagram.md`.
3. Preencha as respostas em `WORKSHEET.md`.
4. Rode o validador local.
5. Faça o Skill Check no MyLearn.

## Critérios de aceite
- Quatro provedores identificados.
- Três casos de uso avaliados com benefício e trade-off.
- Arquitetura conceitual explicada sem prometer que os serviços são emulados.
- Validador local aprovado.
