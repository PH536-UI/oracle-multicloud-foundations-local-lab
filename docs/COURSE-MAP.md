# Mapa do curso para o laboratório

| Módulo do curso | Cenário local | Critério de aceite |
|---|---|---|
| 01. Introdução | inventário e casos de uso sintéticos | diagrama e requisitos registrados |
| 02. Arquitetura | redes Docker e interconexão simulada | comunicação só entre serviços autorizados |
| 03. Onboarding | RBAC fictício e workflow | sem conta, token ou cobrança real |
| 04. Ciclo de vida | inventário declarativo local | plano validado, sem criação externa |
| 05. Resiliência | backup e restore sintéticos | restauração local verificada |
| 06. Migração e segurança | migração de amostra e controles | dados mascarados e auditoria local |

Cada cenário deve ter README, diagrama, dados sintéticos, validações e evidência sanitizada.
