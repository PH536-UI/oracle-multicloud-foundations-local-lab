# Início do laboratório

## Pré-requisitos locais
- Docker Desktop/Engine ativo.
- Terraform instalado.
- Python 3 instalado.
- Nenhuma conta cloud, token ou credencial é necessária.

## Fluxo de estudo
1. Abra `scenarios/01-introduction/README.md`.
2. Assista às duas aulas do módulo 01 no Oracle MyLearn.
3. Preencha `WORKSHEET.md` somente com o caso sintético.
4. Rode `python3 scripts/validate-module-01.py`.

O módulo 01 é conceitual e não exige deploy. Os cenários com Docker e Terraform começam no módulo 02.
